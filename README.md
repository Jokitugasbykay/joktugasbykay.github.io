# JOKIIN-WEBSITE version 1.07

Promo mobile mengikuti sketsa terbaru:
- Baris atas: Promo Terbatas di kiri, X di kanan.
- Baris tengah: diskon persen di kiri dan countdown di kanan.
- Baris bawah: running text di kiri dan Klaim Promo di kanan.

Running text hanya memakai nilai text dari konfigurasi promo. Kode kupon dan diskon tidak lagi ditambahkan otomatis ke marquee. Jika isi pesan promo sendiri menyebut kupon atau diskon, kalimat tersebut tetap dipertahankan.

Marquee tetap memakai dua grup identik untuk loop kontinu. Reduced motion menampilkan pesan statis. Tinggi normal 112 px. Warna coretan sketsa tidak dipakai sebagai warna UI.

Navbar, invoice, dan data server tidak diubah.
